`agent:input` 的 `addInput` 支持 `{{rawInput}}` 占位符——片段产物与原输入互斥，位置由订阅端裁决：

- 拼接结果含 `{{rawInput}}` 时，占位符全部展开为**当轮输入原内容**——原输入嵌在订阅端指定的位置、不再缀尾（如 `'规则…\n\n<user_input>{{rawInput}}</user_input>'` 一条片段即可拼出「块在前、输入收尾」的完整组装，不再依赖 root-input 塑形）。
- 不含占位符 → 维持现状（片段前置 + 原输入缀尾），完全向后兼容。
- 单次展开不递归（原内容含字面占位符不二次处理）；无当轮输入的轮（工具轮/纯续跑轮）占位符展开为空串，展开后全空白不落账（同空片段过滤口径）。
