任务嵌套命名与目录段白名单对齐 agent / tool 规则（`fix(agent,tools)` 6.28.0 同款迁移）：

- **嵌套分隔符 `.` → `_`**：任务名 = `tasks/` 后的目录路径段用 `_` 连接（旧为 `.`）——`src/tasks/a/b/task.ts` 的注册名变为 `a_b`（旧 `a.b`），两种声明文件（task.ts / worker.ts）同规则。
- **目录段字符白名单（构建期报错，不静默净化）**：目录段须匹配 `^[a-zA-Z0-9-]+$`——`_` 被 `/` 规范化独占为嵌套分隔符（段内出现会让「嵌套」与「段内下划线」不可区分），`.` 等其余字符一并拒绝；违例扫描期抛错（含路径与改名指引）。白名单保证「目录路径 → 任务名」映射单射，跨路径同名冲突不再可能出现，重名冲突只剩同目录 task.ts + worker.ts 并存一种形态。

**迁移提示**（业务方需同步修改）：

1. 嵌套任务的引用名：`enqueue('a.b', payload)` → `enqueue('a_b', payload)`；cron 之外按任务名查询/订阅（`subscribe` / `listEvents` / 组投递成员名）同步改。
2. 嵌套任务目录名含 `.` 或 `_` 的需改名（段内只允许字母数字连字符），否则构建报错。
3. 平铺（单层目录）任务不受影响——`send-email` 等名字不变。
